# MyShopping

Java・Servlet・JSP・H2を使用して開発したショッピングサイトです。

## 概要

商品情報の登録・一覧表示など、ショッピングサイトの基本的な機能を実装しています。

JavaのWebアプリケーション開発を学習する中で、Servlet・JSP・DAO・データベースを組み合わせて、MVCを意識した構成で開発しました。

## 使用技術

- Java
- Servlet
- JSP
- HTML / CSS
- H2 Database
- Apache Tomcat
- Eclipse

## 主な機能

- 商品登録
- 商品一覧表示
- 商品情報のデータベース保存
- H2 Databaseとの接続

## システム構成

- Model：商品情報などのデータを管理
- DAO：データベースへの登録・取得処理
- Servlet：リクエストを受け取り、処理を実行
- JSP：画面の表示

## データベース

H2 Databaseを使用しています。

商品情報として以下の項目を管理しています。

- 商品ID
- 商品名
- 価格
- カテゴリ
- メモ

## 開発環境

- Windows
- Eclipse
- Java 25
- Apache Tomcat 11
- H2 Database

## 工夫した点

JavaのWebアプリケーション開発の基本を理解することを目的として、Servlet・JSP・DAO・データベースの役割を分けて開発しました。

また、データベースとの接続やSQLによるデータ登録・取得処理を実際に実装し、Web画面からデータベースまでの処理の流れを理解できるようにしました。
